# Service Menu

Foreman only sells launch services for agent builders.

## Demo Cut

Input:

- Project name and one-line summary.
- Raw screen recording clips.
- Preferred product URL or repo URL.
- Desired tone.
- Deadline.

Output:

- Captioned horizontal demo.
- Captioned vertical demo.
- Thumbnail.
- Delivery receipt with output hashes.

Price: 15 to 25 USDT.

## Listing Audit

Input:

- OKX.AI listing draft or service page.
- Live URL or repo URL.
- Target category.
- Intended pricing.

Output:

- Review-blocking issues.
- Claim cleanup notes.
- Scope clarity fixes.
- Buyer-flow stress test notes.

Price: 5 to 10 USDT.

## Launch Pack

Input:

- Everything required for Demo Cut and Listing Audit.

Output:

- Demo Cut deliverables.
- Listing Audit deliverables.
- Announcement post draft.
- Proof pack.

Price: 30 to 40 USDT.
