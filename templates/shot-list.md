# Shot List Template

This is a public delivery template, not the private hackathon recording script.

## Fields

- Project name
- Buyer goal
- Target viewer
- Core product action
- Raw clips available
- Required screenshots
- Required proof beat
- Final call to action

## Scene Structure

1. Problem or raw state.
2. Product action.
3. Output/result.
4. Proof or receipt.
5. Call to action.
